# Thư mục `assets/`

Thư mục này chứa các tài nguyên hình ảnh vector (SVG) và âm thanh của website chúc mừng 20/10:

- `favicon.svg`: Biểu tượng bông hoa 6 cánh lấp lánh trên tab trình duyệt.
- `bouquet.svg`: Bó hoa hồng & tulip nghệ thuật sử dụng ở Chương 5 và Chương 6.
- **(Tùy chọn) Nhạc nền MP3**: Mặc định website đã tích hợp bộ tổng hợp âm thanh **Web Audio API Piano & Celesta** tự động phát giai điệu dịu dàng ngay khi mở hộp quà mà không cần file ngoài. Nếu bạn muốn dùng bản nhạc `.mp3` riêng, hãy chép file vào `assets/music.mp3` và cập nhật `musicUrl: "assets/music.mp3"` trong `WOMENS_DAY_CONFIG` ở đầu file `script.js`.
